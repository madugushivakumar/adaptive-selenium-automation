Audited & Verified Engineering Guardrails

  • Zero Hardcoded Selectors: No fixed IDs (`#fname`), fixed names, or absolute XPaths used.
  • Strict Value Verification: Exact normalized and word-boundary matching (`TextNormalizer.MatchesWord`, `IsMatchForValue`) prevents substring collisions (e.g. Female matching Male).
  • Independent Fixture Telemetry: `scripts/run-all-fixtures.ps1` parses generated JSON telemetry and independently validates each field's expected vs actual values.
  • Refusal on Ambiguity: When competing fields are equidistant (Δ ≤ 5.0%), framework cleanly refuses arbitrary interaction.
  • Disabled & Hidden Element Guards: Prevents interaction with inactive DOM nodes and reports descriptive diagnostic explanations.
